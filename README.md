# eDEX-ui Nix Flake
A nix flake for [exed-ui](https://github.com/GitSquared/edex-ui) project.

# Warning!
This project is EOL since 2021. Probably shouldn't be used. This flake was made purely for fun.

# How to run
```bash
nix run github:szymon-jozef/edex-ui-flake
```

# How to install
```bash
nix profile add github:szymon-jozef/edex-ui-flake
```
